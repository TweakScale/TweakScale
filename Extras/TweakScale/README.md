# TweakScale /L :: Extras

This directory contains some patches *et all* that **SHOULD NOT** be usually installed, unless under some pretty borderline situations:

* You have some really, really old 3rd party add'on that I didn't managed to find anymore, or an older version from it on a time in which the add'on author wasn't supporting TweakScale yet.
	+ Read [this](./Deprecated/README.md) for more information.
* You reached me with an old lingering problem with a 3rd party add'on that I can't fix or send fixes to the author by a reason or another, and I had to implement some blunt Hot Fixes to survive the ordeal.
	+ Read [this](./HotFixes/README.me) for more information.
* Some unfixable problem in which I had to bluntly withdraw TweakScale support after patching.
	+ Read [this](./Workarounds/README.me) for more information.

In all these cases, you should not install any of these files without dropping a line to me first, or at very least reaching a FAQ or HOWTO that describes exactly, without the slightest doubt, the situation you are facing now. And, definitively, **never** install any of them without reading the content first, where the problem it solves is explained so you can be absolutely sure this is what you need.

If you are not facing any situation, then definitively you **SHOULD NOT** install any of these!!! :)

Reach me on any of contacts listed [here](https://ksp.lisias.net/) (on the bottom of the page) if you have any questions, I will glad to answer!
